# Design sources

Source files for images used in the book. They live outside `assets/`
because everything in `assets/` is copied to the website.

- `tax-buckets/` — PowerPoint and Infinite Design files for
  `assets/images/financial_math/Tax-buckets-3.png` (Section 1.5).
- `cover/` — uncropped original of the cover photo by Denys Nevozhai
  (Unsplash License); the book uses `assets/images/denys-nevozhai-crop.jpg`.

All TikZ figures are written inline in the `.ptx` source files.
